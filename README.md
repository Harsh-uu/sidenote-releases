# Sidenote

A fast, focused notes app for macOS: folders, tags, checklists, tables, rich text, and a gallery view.

This repository hosts **downloads and updates only**.

## Download

Get the latest `.dmg` from **[Releases](https://github.com/Harsh-uu/sidenote-releases/releases/latest)**. One download works on both Apple Silicon and Intel Macs.

## First launch

Sidenote isn't signed with an Apple Developer certificate yet, so macOS blocks it the first time:

1. Open the `.dmg` and drag **Sidenote** into **Applications**.
2. Open Sidenote. macOS says it can't verify the app; click **Done**.
3. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Sidenote.

You only need to do this once.

## Updates

Sidenote checks this page for new versions when it starts, and you can check anytime from **Sidenote → Check for updates…**. When a new version is out, click **Download** and replace the app in Applications. Your notes are kept.
